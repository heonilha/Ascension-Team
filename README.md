기존 데모 보관 저장소: [AscensionPrototype](https://github.com/kimminseoung-source/AscensionPrototype). 2026-10-27 분리 시점의 39개 커밋과 최신 보스 개선(91fc34c)을 보관한다. 이후 공동 개발은 Ascension-Team에서 진행한다. 언리얼 프로젝트 이름과 모듈 이름은 AscensionPrototype을 유지한다.

## 게임 (DungeonEscape2)

4팀 × 3명이 하나의 PvP 맵에서 바로 시작해 몬스터를 사냥하고 서로 싸우는 배틀로얄 핵앤슬래시다. 4라운드 동안 자기장이 좁아지며 마지막까지 살아남은 1팀이 승리한다. 별도의 PvE 시간·PvE 스테이지는 없다.

- 기획 원본: [11.26 기획안](Docs/11.26기획안.md)
- 데모 범위와 역할 분담: [데모 작업 분담](Docs/데모_작업분담.md)

이전 기획(각성과 탐욕의 탑: 1인 등반·수문장·각성 제단·장비 약탈)은 폐기했다. 기존 문서는 Git 이력에만 남긴다.

## 현재 코드 상태

현재 코드는 이전 기획으로 만든 전투 프로토타입이며 새 기획으로 바꾸는 중이다. 새 데모에서 재사용할 부분은 3인칭 이동·카메라·회피, 검기 발사·충전, 몬스터 AI와 모델·애니메이션, 폐허 정원 맵, 서버 접속·서버 권한 이동·회피/공격 서버 판정이다. 수문장·층 이동·각성 제단·장비 약탈·자동 번개/칼날은 새 기획에 없으므로 데모 작업 중 정리한다. 아래 조작과 검증 스크립트는 현재 코드 기준이다.

온라인(서버 접속) P0: [온라인 P0 실행 안내](Docs/온라인_P0_실행.md). 옵션 없이 실행하면 기존 1인용 데모와 같다.

엔진: 로컬 설치 파일에서 Unreal Engine 5.8.3 확인. 별도 배포 exe는 아직 없다.

## 조작

| 키 | 행동 |
|---|---|
| WASD / 마우스 | 카메라 기준 이동(이동·정지 모두 몸은 카메라 정면으로 회전) / 카메라 회전 |
| 좌클릭 / 우클릭 | 일반 검기 / 누르고 충전한 뒤 놓으면 강한 검기(이동 가능) |
| Space | 누르고 있는 WASD 방향으로 회피. 이동 입력이 없으면 카메라 전방 |
| Tab | 가장 가까운 시야 내 적 락온 / 해제 |
| Q | 주변 범위 스킬 |
| E | 중앙 제단: 수문장 소환 / 처치 후 다음 층 이동. 금색 각성 제단: 각성 선택(생명당 최대3회) |
| I / ↑↓ / Enter | 가방 열기 / 장비 선택 / 장착·교체 |
| 1 / 2 / 3 | 각성 선택, 최대 보유 중에는 교체할 슬롯 선택 |
| Esc | 각성 획득 또는 교체 포기 |
| R | 성장과 장비를 초기화하고 1층에서 새 도전 |
| N | 생존 모드 설명 안내(증원은 자동). 기존 검증 모드에서는 다음 전투 |
| Z / X / C / V | 스킬 슬롯 1~4 (임시 키). 스킬을 쓰면 해당 무기로 자동 교체 |
| F | 검 ↔ 활 교체 (임시 키) |

경험치 성장 UI에서는 세계와 생존 시간이 멈춘다. 1/2/3으로 선택하거나 Esc로 포기하면 재개한다. 엘리트 처치의 기존 각성 선택은 세계를 멈추지 않는다. 선택 중 이동·회피는 가능하고 공격·스킬은 막는다.

강화공격은 최소0.6초 충전해야 발사한다. 그 전에 놓으면 후딜레이 없이 취소된다. 최소 충전의 기본 피해는49/반경102cm이며 최대3초까지 강화된다. 장비 드롭은 현재 모델·라벨·획득을 임시 숨김 처리했다.

일반 플레이에서는 검기를 발사하며 계속 이동한다. 일반 공격 간격은 0.72초이며 휘두르기 시작 0.28초 후 발사한다. 기본 검기는 먼저 만난 한 명에게 맞고 사라진다. 레벨업 세 번째 검기 관통 강화 선택으로 대상 수를 1→2→3→4명까지 늘릴 수 있으며 사망 시 초기화된다. 우클릭은 최대 3초 충전하고 놓으면 0.34초 후 발사한다. 충전 시간에 비례해 기본 피해 35→105, 검기 반경 70→230cm(폭 약 3.3배), 강공격 관통 4→10명으로 증가한다. 비행 유지 시간도 1.2→2초로 늘어난다. 충전 게이지에 시간·피해 배수·폭 배수를 표시하고 색·범위선·발사 검기 두께를 함께 키운다. 발사 후 공격 동작은 0.85초이며 탐욕의 강공격은 기존 빈틈 0.45초를 추가한다. 회피·사망·가방 열기·성장 선택은 충전을 취소한다. 상체 검 동작과 하체 달리기를 분리하고 전환을 부드럽게 섞는다. 기존 근접 공격의 이동 차단은 검증 모드에만 유지한다. 회피는 진행 방향으로 몸을 돌리고 0.65초 동안 최대 300cm 이동한다. 무적은 시작 후 0.15초이며 쿨다운은 1초다. 벽은 이동을 막지만 구르기 동작은 끝까지 재생한다.

## 현재 제한

- 서버 접속·온라인 이동·서버 판정 클라이언트 코드는 `feature/online-base`에 합쳤고, main 반영은 PR 검토 후다. 서버는 별도 저장소 Ascension-Server에 있다.
- 스킬 공통 틀(무기 교체·슬롯·쿨타임·마나)과 검 강타·활 속사 예시만 있다. 스킬 피해는 1인 플레이 몬스터에만 적용되고 서버 판정은 아직 없다. 자세한 내용은 [데모 작업 분담](Docs/데모_작업분담.md)의 "스킬 공통 틀".
- 새 기획의 팀 4×3, 라운드·자기장, 부활, 레벨·스킬 포인트·스탯, 검/활 스킬, 특성, 균열, 황금 고블린은 아직 구현되지 않았다. 진행 상황은 [데모 작업 분담](Docs/데모_작업분담.md)에 기록한다.
- 캐릭터 모델과 동작은 초기 적용 단계이고, 검은 손에 붙인 임시 도형이다. 활 모델·동작은 없다.
- 공격·범위·전조는 개발용 선으로 표시한다. 자동 시험은 난이도나 재미를 검증하지 않는다.
