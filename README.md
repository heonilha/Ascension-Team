# AscensionPrototype

개발 저장소: [GitHub · AscensionPrototype](https://github.com/kimminseoung-source/AscensionPrototype) (비공개). 기능별 한국어 커밋과 개발 기록을 관리한다.

새로운 3인칭 검 액션·각성 전투 프로토타입. 기존 TowerDemo와 별개의 프로젝트다.

첫 단계: 전투층 1개에서 3인칭 이동, 검 일반/강공격, 회피, 강화 반격, Q 범위 스킬, 선택형 락온, 검병·돌진병·2연격 엘리트, 각성 선택·교체를 구현했다. 자동 시험과 실제 화면 검증 결과는 Docs/데모_검증결과.md에 별도로 기록한다.

현재 일반 플레이는 검병·돌진병·엘리트 7마리를 안전한 무작위 위치에 배치한다. 전멸 후 체력 20을 회복하며 N으로 다음 전투를 시작한다. 다음 전투는 장비·각성을 유지하고 적 수를 최대 10까지 늘린다. 이는 전투장 반복 기능이며 탑의 층 진행·개인 타이머는 아직 구현하지 않았다.

명중 시 짧은 히트 스톱, 작은 카메라 흔들림, 중앙 명중 표시, 피해 숫자·불꽃과 직접 합성한 효과음을 적용했다. 빗나간 검에는 명중 효과를 주지 않는다.

기획: [합의한 기획](Docs/합의한_기획.md).

엔진: 로컬 설치 파일에서 Unreal Engine 5.8.3 확인. 별도 배포 exe는 아직 없다.

Meshy 공통 캐릭터를 플레이어와 적에 재사용한다. 대기·달리기·검 공격·강공격·회피 동작을 적용했다. 검·방어구 획득, 장착, 사망 시 장비만 드롭하는 규칙도 구현했다.

## 빌드와 실행

PowerShell에서 이 프로젝트 폴더 기준으로:

```powershell
.\Scripts\BuildDemo.ps1
.\Scripts\OpenDemo.ps1
```

원본은 이 폴더이며 한글 경로의 빌드 문제를 피하도록 C:\Users\doboh\.codex\builds\AscensionPrototype에 빌드 사본을 만든다. 기존 TowerDemo를 복사하거나 변경하지 않는다. OpenDemo.ps1 -Editor는 에디터를 연다. 소스 수정 뒤에는 먼저 빌드한다.

## 조작

| 키 | 행동 |
|---|---|
| WASD / 마우스 | 카메라 기준 이동(이동·정지 모두 몸은 카메라 정면으로 회전) / 카메라 회전 |
| 좌클릭 / 우클릭 | 일반 검 공격 / 강공격 |
| Space | 마지막 이동 방향 회피. 이동 방향이 없으면 카메라 전방 |
| Tab | 가장 가까운 시야 내 적 락온 / 해제 |
| Q | 주변 범위 스킬 |
| E | 가까운 가방에서 장비 획득 / 금색 원 제단에서 각성 선택(생명당 최대 3회) |
| I / ↑↓ / Enter | 가방 열기 / 장비 선택 / 장착·교체 |
| 1 / 2 / 3 | 각성 선택, 최대 보유 중에는 교체할 슬롯 선택 |
| Esc | 각성 획득 또는 교체 포기 |
| R | 1인용 전투 테스트 전체 재설정 |
| N | 몬스터 전멸 후 장비·각성을 유지하고 다음 랜덤 전투 시작 |

엘리트 처치도 각성 선택을 제공한다. 각성 UI를 열어도 적과 세계는 계속 움직인다. 선택 중 이동·회피는 가능하고 공격·스킬은 막는다.

공격 중에는 이동 입력과 관성을 막는다. 회피는 진행 방향으로 몸을 돌리고 0.65초 동안 최대 300cm 이동한다. 무적은 시작 후 0.15초이며 쿨다운은 1초다. 벽은 이동을 막지만 구르기 동작은 끝까지 재생한다.

## 현재 제한

- 실제 1인용 전투 실험이다. 봇 파티·네트워크 PvP는 없다.
- 검·방어구는 고유 ID를 가진 장비다. 적 처치와 플레이어 사망 시 가방에 드롭하며 E로 획득한다. 각성은 사망 시 사라지고 가방에 들어가지 않는다. 가방은 180초 후 사라진다. 현재 약탈은 1인용 규칙 시험이며 다른 유저와의 동시 획득은 미구현이다.
- 다층 등반·개인 타이머·베이스 예약·상점은 없다.
- R은 캐릭터와 적을 초기화하는 개발용 재설정이다. 기존 드롭 가방은 유지하지만 살아서 R을 누르면 기존 장비를 드롭하지 않는다. 향후 멀티플레이 개인 재도전의 구현으로 간주하지 않는다.
- 캐릭터 모델과 동작은 초기 적용 단계다. 공격 간 애니메이션 보간과 적 전용 공격 동작은 아직 없다. 검은 손에 붙인 임시 도형이다.
- HUD·조작 안내·적/제단 이름·각성 선택/교체·사망/재시작 안내는 한글이다. 검 명중 합성 효과음은 적용했고 환경음·피격·회피 소리는 아직 없다. 탐욕 회피의 소음은 알림과 몬스터 감지 확대 규칙으로만 표현한다.
- 공격·범위·전조는 개발용 선으로 표시한다. 자동 시험은 난이도나 재미를 검증하지 않는다.

## 자동 검증

```powershell
.\Scripts\VerifyDemo.ps1
.\Scripts\VerifyDemo.ps1 -View
```

개발 검증은 -AscensionVerify 옵션에서만 수행한다. -View는 3인칭 화면을 저장하고 종료한다.
