# AscensionPrototype

개발 저장소: [GitHub · AscensionPrototype](https://github.com/kimminseoung-source/AscensionPrototype) (비공개). 기능별 한국어 커밋과 개발 기록을 관리한다.

새로운 3인칭 검 액션·각성 전투 프로토타입. 기존 TowerDemo와 별개의 프로젝트다.

첫 단계: 전투층 1개에서 3인칭 이동, 검 일반/강공격, 회피, 강화 반격, Q 범위 스킬, 선택형 락온, 검병·돌진병·2연격 엘리트, 각성 선택·교체를 구현했다. 자동 시험과 실제 화면 검증 결과는 Docs/데모_검증결과.md에 별도로 기록한다.

현재 일반 플레이는 개방형 폐허 정원에서 사냥 → 중앙 수문장 소환/처치 → 2층 → 마지막 휴식 구역으로 이어지는 1인용 등반 데모다. 준비됐을 때 중앙 제단 근처에서 E를 눌러 수문장을 소환하며, 처치해야 중앙 출구가 열린다. 5분 자동 소환과 강제 이동은 없다. 소환 후 추가 증원은 멈추고 기존 몬스터는 남는다. 1층 수문장 체력300, 2층450이며 기존 엘리트 모델·2연격을 재사용한다. 층 이동은 성장·각성·장비를 유지하고, 휴식 구역에서는 적이 없어지고 체력이 회복된다. 세 구간은 같은 맵을 재사용하는 초기 구현이다.

이동하며 검기를 직접 발사하고 회피하며 자동 번개·회전 칼날이 보조한다. 경험치 구슬은 접근 획득하며 레벨업 시 시간을 멈추고 세 가지 강화 중 하나를 고른다. 시작 적은 1층12/2층14마리, 2.5~1.5초마다4~8마리 증원하며 수가 적으면 중간 보충한다. 일반/엘리트 동시48마리, 보스 포함49마리다. 몬스터 체력은 층 기준으로 고정하며 2층은25% 높다. 체류시간은 증원 압박을 높이지만 몬스터 체력을 높이지 않는다. 실제 멀티 합류·몹 몰이 방지 규칙은 아직 구현되지 않았다.

명중 시 짧은 히트 스톱, 작은 카메라 흔들림, 중앙 명중 표시, 피해 숫자·불꽃과 직접 합성한 효과음을 적용했다. 빗나간 검에는 명중 효과를 주지 않는다.

기획: [합의한 기획](Docs/합의한_기획.md).

엔진: 로컬 설치 파일에서 Unreal Engine 5.8.3 확인. 별도 배포 exe는 아직 없다.

플레이어는 인간형, 몬스터는 별도 해골 망령 모델을 사용한다. 대기·달리기·검 공격·강공격·회피 동작을 적용했다. 검·방어구 획득, 장착, 사망 시 장비만 드롭하는 규칙도 구현했다.

## 빌드와 실행

PowerShell에서 이 프로젝트 폴더 기준으로:

```powershell
.\Scripts\BuildDemo.ps1
.\Scripts\OpenDemo.ps1
```

원본은 이 폴더이며 한글 경로의 빌드 문제를 피하도록 C:\Users\doboh\.codex\builds\AscensionPrototype에 빌드 사본을 만든다. 기존 TowerDemo를 복사하거나 변경하지 않는다. OpenDemo.ps1 -Editor는 에디터를 연다. 소스 수정 뒤에는 먼저 빌드한다.

## 조작

| 키 | 행동 |
|---|---|
| WASD / 마우스 | 카메라 기준 이동(이동·정지 모두 몸은 카메라 정면으로 회전) / 카메라 회전 |
| 좌클릭 / 우클릭 | 일반 검기 / 누르고 충전한 뒤 놓으면 강한 검기(이동 가능) |
| Space | 누르고 있는 WASD 방향으로 회피. 이동 입력이 없으면 카메라 전방 |
| Tab | 가장 가까운 시야 내 적 락온 / 해제 |
| Q | 주변 범위 스킬 |
| E | 중앙 제단: 수문장 소환 / 처치 후 다음 층 이동. 금색 각성 제단: 각성 선택(생명당 최대3회) |
| I / ↑↓ / Enter | 가방 열기 / 장비 선택 / 장착·교체 |
| 1 / 2 / 3 | 각성 선택, 최대 보유 중에는 교체할 슬롯 선택 |
| Esc | 각성 획득 또는 교체 포기 |
| R | 성장과 장비를 초기화하고 1층에서 새 도전 |
| N | 생존 모드 설명 안내(증원은 자동). 기존 검증 모드에서는 다음 전투 |

경험치 성장 UI에서는 세계와 생존 시간이 멈춘다. 1/2/3으로 선택하거나 Esc로 포기하면 재개한다. 엘리트 처치의 기존 각성 선택은 세계를 멈추지 않는다. 선택 중 이동·회피는 가능하고 공격·스킬은 막는다.

강화공격은 최소0.6초 충전해야 발사한다. 그 전에 놓으면 후딜레이 없이 취소된다. 최소 충전의 기본 피해는49/반경102cm이며 최대3초까지 강화된다. 장비 드롭은 현재 모델·라벨·획득을 임시 숨김 처리했다.

일반 플레이에서는 검기를 발사하며 계속 이동한다. 일반 공격 간격은 0.72초이며 휘두르기 시작 0.28초 후 발사한다. 기본 검기는 먼저 만난 한 명에게 맞고 사라진다. 레벨업 세 번째 검기 관통 강화 선택으로 대상 수를 1→2→3→4명까지 늘릴 수 있으며 사망 시 초기화된다. 우클릭은 최대 3초 충전하고 놓으면 0.34초 후 발사한다. 충전 시간에 비례해 기본 피해 35→105, 검기 반경 70→230cm(폭 약 3.3배), 강공격 관통 4→10명으로 증가한다. 비행 유지 시간도 1.2→2초로 늘어난다. 충전 게이지에 시간·피해 배수·폭 배수를 표시하고 색·범위선·발사 검기 두께를 함께 키운다. 발사 후 공격 동작은 0.85초이며 탐욕의 강공격은 기존 빈틈 0.45초를 추가한다. 회피·사망·가방 열기·성장 선택은 충전을 취소한다. 상체 검 동작과 하체 달리기를 분리하고 전환을 부드럽게 섞는다. 기존 근접 공격의 이동 차단은 검증 모드에만 유지한다. 회피는 진행 방향으로 몸을 돌리고 0.65초 동안 최대 300cm 이동한다. 무적은 시작 후 0.15초이며 쿨다운은 1초다. 벽은 이동을 막지만 구르기 동작은 끝까지 재생한다.

## 현재 제한

- 실제 1인용 전투 실험이다. 봇 파티·네트워크 PvP는 없다.
- 장비 이전·180초 가방 소멸 규칙은 보존하지만 일반 플레이의 드롭 표시와 획득은 숨겼다. 다른 유저와의 동시 약탈은 미구현이다.
- 두 전투층과 마지막 휴식 상태를 같은 지형에서 시험한다. 개인별 층 진행·멀티 베이스 예약·상점·몹 몰이 방지는 없다. 한 사람의 진행을 공유 층의 멀티 규칙으로 간주하면 안 된다.
- R은 캐릭터와 적을 초기화하는 개발용 재설정이다. 기존 드롭 가방은 유지하지만 살아서 R을 누르면 기존 장비를 드롭하지 않는다. 향후 멀티플레이 개인 재도전의 구현으로 간주하지 않는다.
- 캐릭터 모델과 동작은 초기 적용 단계다. 생존 플레이어는 상하체 동작 분리와 기본 보간을 적용했다. 적과 기존 근접 검증 모드의 동작 전환은 초기 수준이다. 이동 방향별 전용 옆걸음 동작은 아직 없다. 적은 전용 해골 망령 모델을 크기·색으로 구분하고 검병·지휘관에 검 공격 동작을 적용했다. 검은 손에 붙인 임시 도형이다.
- HUD·조작 안내·적/제단 이름·각성 선택/교체·사망/재시작 안내는 한글이다. 검 명중 합성 효과음은 적용했고 환경음·피격·회피 소리는 아직 없다. 탐욕 회피의 소음은 알림과 몬스터 감지 확대 규칙으로만 표현한다.
- 공격·범위·전조는 개발용 선으로 표시한다. 자동 시험은 난이도나 재미를 검증하지 않는다.
