# 개발 진행

최신 정면 보정: 고정된 상대 Yaw만으로는 생성된 대기 동작의 몸 방향 오프셋이 남았다. 양 어깨·머리·골반으로 실제 몸 정면을 계산해 대기·이동 시 캡슐의 정면에 맞추도록 바꿨다. 렌더링 시험은 입력을 차단해 외부 마우스 움직임의 영향을 제거한다. 모델 정면과 카메라 방향 일치 시험 통과(dot 1.000). 앞선 고정 각도 보정을 대체하는 최종 몸 방향 처리다.

추가 렌더링 보정: 랜덤 전투 화면에서 앞선 대기 자세 90도 보정이 모델을 옆으로 돌리는 것을 재확인했다. 초기·대기·검 공격은 상대 Yaw 180, 달리기·구르기는 270으로 구분해 다시 정렬했다. RandomCombat.png와 CombatImpact.png는 최신 실제 화면이다. 명중 시 적을 둘러싸던 흰색 디버그 구를 제거해 피해 숫자와 불꽃의 가독성을 높였다.

최신 전투 확장: 일반 플레이에 랜덤 몬스터 7마리(검병·돌진병·엘리트)를 배치한다. 시작 위치에서 최소 450cm, 몬스터 간 최소 180cm를 확보하고 벽·기둥 충돌 위치를 거부한다. 전멸 보상은 체력 +20이며 N으로 장비·각성을 유지한 다음 전투를 시작한다. 적 수는 최대 10마리, 체력 증가는 차수당 8%(최대 40%)다. 층 이동과 구분하는 전투장 반복 기능이다.

타격감 확장: 실제 검 명중에만 0.045초 개인 히트 스톱, 0.12초 카메라 흔들림, 명중 표시·피해 숫자·불꽃·합성 효과음을 적용했다. 약한 검병만 짧게 경직하며 돌진병·엘리트의 전조는 유지한다. 새로운 Meshy 요청이나 결제는 없다. 전투 회귀 시험과 20개 시드 생성 시험을 통과했다.

시작 자세 보정: 사용자가 시작 직후 대기 자세에서 몸이 왼쪽으로 90도 틀어진 것을 확인했다. 초기 메시와 대기 클립의 상대 Yaw를 180→270으로 바꿔 오른쪽으로 90도 보정했다. 공격 클립의 별도 회전은 유지한다. BuildIdleAxisCalibration.log에 빌드 결과를 기록한다.

최신 조작 변경: 사용자 요청으로 일반 이동·정지 모두 몸이 카메라 정면을 바라보도록 변경했다. 앞서 적용한 이동 방향 회전을 대체한다. 공격 중 이동 금지와 구르기 진행 방향은 유지한다. 현재 옆·뒤 이동 전용 애니메이션은 없어 달리기 클립을 공유하며, 발 동작은 추가 보정이 필요하다.

2026-10-11. 새 프로젝트의 첫 1인용 전투 테스트를 구현하고 빌드했다.

완료 범위: 엔진 설치 확인, 새 C++ 모듈·맵·빌드/실행 스크립트, 3인칭 이동·카메라·락온, 일반 연속 검 공격·강공격·회피·정확한 회피 반격·Q, 일반 적 2종·2연격 엘리트, 각성 6종 중 후보 3개 선택·최대 3개 보유·교체·포기·사망 초기화, 제단·엘리트 보상, 개발용 자동 검증.

후속 완료: 검·방어구 고유 ID, 최대 12칸 가방, 장착·교체, 실제 피해/방어 수치 반영, 몬스터 장비 드롭, 사망 시 장비만 드롭. E로 거리와 시야를 확인한 뒤 하나씩 획득한다. 각성은 사망 시 사라지고 약탈되지 않는다. 예리한 검 +4, 묵직한 검 +8, 철제 방어구 피해 감소 3(최소 피해 1).

아직 없음: 개인별 다층 등반, 베이스, 봇 파티, 실제 네트워크, 상점, 음향·독립 실행 패키지. 모델·애니메이션은 초기 적용 단계로 자연스러운 전환과 적 공격 동작이 더 필요하다.

현재 임시 수치: 체력 100, 이동 450cm/s, 검 20 피해·190cm·100도·0.44초, 강공격 35 피해·230cm·130도·0.85초, 회피 최대 300cm·0.65초·초반 무적 0.15초·쿨다운 1초, 정확한 회피 후 2초 내 다음 검 공격 +10, Q 피해 25·반경 320cm·쿨다운 6초.

사용자 플레이 피드백 반영: 카메라 방향에 몸을 고정하던 코드를 이동 방향 회전으로 바꿨다. 공격 시작 시 이동 관성과 대기 입력을 끊고 공격 중 이동을 막는다. 구르기는 진행 방향을 바라보며 부드러운 속도 곡선으로 이동한다. 벽에 닿아도 동작이 갑자기 종료되지 않으며 연속 공격·회피마다 애니메이션을 다시 시작한다. 탐욕 강공격의 추가 회복 시간은 공격 동작 자체를 느리게 만들지 않는다. Meshy 추가 생성 없음.

일반 각성: 반격 추가 +15, 일반 3타 +12, Q 반경 440cm, Q 쿨다운 4초. 탐욕 각성: 회피 폭발 18·반경 260cm와 1500cm 내 적 5초 경계 확대, 강공격 +25와 회복 추가 0.45초.

임시 도형으로 전투를 실험하기 위한 수치이며 최종 밸런스가 아니다. 실제 소리와 다른 유저에게 위치 노출하는 기능은 아직 없고 회피 폭발은 적의 경계 확대만 적용한다.

작업 중 사용량 확인을 계속했고 이번 확인에서 5시간 잔여율 54%. 사용자 기준은 5시간 잔여율 30% 이하에서 중단. 주간 한도는 중단 기준에서 제외한다. 자동 리셋·재개는 하지 않는다.

다음 우선순위는 애니메이션과 공격 판정 시점 조정, 적 전조 가독성, 전투층 진행과 보상 루프다. 개발용 R은 캐릭터·적을 초기화하고 기존 드롭을 남긴다. 살아서 R을 누르면 장비를 드롭하지 않으므로 최종 재도전 규칙과 다르다.

후속 요청으로 내부 UI를 한글화했다. 각성/탐욕 설명, 선택·교체·포기, 체력·조작·락온, 사망·재도전, 가방·장착, 적·제단 이름을 수정했다. 선택 화면을 두 줄 설명으로 정리하고 교체 중에는 현재 보유 슬롯을 보여준다. 실제 한글 렌더링 확인 완료.

Meshy 직접 REST API 인증과 잔액 조회를 확인했다. 공통 인간형 모델·리깅·대기·달리기·검 공격·강공격·회피 동작을 적용했고 플레이어와 적이 모델을 재사용한다. 스켈레탈 메시 충돌은 끄고 기존 캡슐 판정을 유지했다. 원래 1,700 중 32 사용, 잔액 1,668. 누적 사용 최대 700·잔액 최소 1,000·추가 결제 금지를 요청 스크립트에서 검사한다. 반복 생성 대신 기존 모델을 수정하고 재사용한다. 영수증과 원본은 Assets/Meshy/SharedKnight에 보존한다.
