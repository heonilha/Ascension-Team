# 온라인 P0 실행 안내

작성일: 2026-10-28. 서버 담당(Heonilha).

P0 목표는 **같은 팀 코드로 접속한 플레이어끼리 같은 층에서 서로 움직이는 모습을 보는 것**이다. 전투 판정·몬스터 동기화는 아직 없다.

## 구성

| 위치 | 내용 |
|---|---|
| 서버 저장소 `Ascension-Server` (별도) | GCC·C++26·asio 서버, 봇 클라이언트, **프로토콜 원본** `protocol/AscensionProtocol.h` |
| 이 저장소 `Source/AscensionPrototype/AscensionProtocol.h` | 프로토콜 **복사본**. 직접 고치지 않는다 |
| `CLNetSession.h/.cpp` | 서버 접속 액터. 수신 스레드 + 게임 스레드 패킷 처리, 15Hz 이동 전송 |
| `CLRemoteHero.h/.cpp` | 다른 플레이어의 겉모습. 서버 위치를 0.1초 늦게 보간해서 그린다 |
| `CombatLab.h/.cpp` | `-AscensionServer` 옵션이 있을 때만 온라인 모드. 몬스터 생성을 끄고 HUD에 접속 상태 표시 |
| `Scripts/OpenOnline.ps1` | 온라인 옵션으로 게임 실행 |

옵션 없이 실행하면 기존 1인용 데모와 똑같이 동작한다. 자동 검증 옵션(`-AscensionVerify` 등)과 함께 쓰면 온라인 모드가 켜지지 않는다.

## 실행 순서 (한 PC에서 두 클라이언트)

1. **서버 켜기**: WSL 터미널에서 서버 저장소를 빌드하고 실행한다. 자세한 방법은 서버 저장소 README 참고.
   ```bash
   ./build/debug/ascension_server --port 7777
   ```
2. **클라이언트 빌드**: PowerShell에서 이 저장소 폴더로 이동한 뒤, 영문 경로의 빌드 폴더를 지정한다.
   ```powershell
   .\Scripts\BuildDemo.ps1 -BuildRoot C:\Builds\AscensionPrototype
   ```
3. **클라이언트 두 개 실행**: 이름만 바꿔 두 번 실행한다. 팀 코드가 같아야 같은 층에 들어간다.
   ```powershell
   .\Scripts\OpenOnline.ps1 -BuildRoot C:\Builds\AscensionPrototype -Name player1 -Team 1
   .\Scripts\OpenOnline.ps1 -BuildRoot C:\Builds\AscensionPrototype -Name player2 -Team 1
   ```
4. **확인**: 체력바 위 하늘색 줄에 `온라인 · 팀 1 · 같은 층 2/3명 · 지연 Nms`가 보이고, 상대 캐릭터 머리 위에 이름이 보이면 성공이다.

다른 PC의 서버에 붙을 때는 `-Server 192.168.0.10:7777`처럼 서버 PC의 IPv4 주소를 넣는다.

## 규칙

- 한 팀(층 인스턴스)은 최대 3명이다. 4번째는 "팀 방이 가득 찼습니다"가 표시된다.
- 프로토콜을 바꿀 때는 서버 저장소의 원본을 고치고 `kVersion`을 올린 뒤, 이 저장소의 복사본도 같은 PR 시점에 갱신한다. 버전이 다르면 서버가 로그인을 거부하고 HUD에 버전 불일치가 표시된다.

## P0의 한계 (다음 단계에서 바꿀 것)

- **이동은 클라이언트가 위치를 보내고 서버가 검증하는 방식이다.** 서버는 속도(토큰 버킷)와 맵 범위를 확인하고 벗어나면 되돌린다(`S_Correction`). 합의한 "판정은 서버" 원칙에 맞추려면 서버에 충돌 지형이 필요하다. 지형이 준비되면 입력 전송 + 서버 이동 계산으로 바꾼다.
- 몬스터·수문장·경험치·장비 드롭은 온라인 모드에서 꺼져 있다.
- 공격·강공격·회피는 상대 화면에 **애니메이션만** 보인다. 피해 판정은 없다.
- R(새 도전)의 시작 위치 순간이동은 서버가 거부해 원래 자리로 돌아올 수 있다.
- 서버 주소는 IPv4만 지원한다(`localhost`는 127.0.0.1로 바꿔 처리).
- 이름은 UTF-8 31바이트까지(한글 약 10자)만 전송된다.
- 이 변경은 Linux에서 서버·봇 테스트만 했다. **언리얼 빌드와 실제 두 클라이언트 접속은 Windows PC에서 확인이 필요하다.**
