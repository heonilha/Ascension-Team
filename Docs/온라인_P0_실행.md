# 온라인 실행 안내

처음 작성: 2026-10-28(P0). 2026-11-27 배틀로얄 매치(프로토콜 v5) 기준으로 다시 정리. 서버 담당(Heonilha).

온라인에서는 **같은 판 번호로 접속한 최대 4팀 × 3명이 한 맵에서 바로 시작**해 서버 몬스터를 사냥하고 다른 팀과 싸운다. 라운드마다 자기장이 좁아지고 마지막까지 남은 1팀이 이긴다. 규칙 원본은 [11.26 기획안](11.26기획안.md), 서버 쪽 세부는 서버 저장소 README의 "매치"다.

## 구성

| 위치 | 내용 |
|---|---|
| 서버 저장소 `Ascension-Server` (별도) | Rust 서버(`rust/`), C++ 봇·시험 도구, **프로토콜 원본** `protocol/AscensionProtocol.h`·`protocol/AscensionMovement.h` |
| `Source/AscensionPrototype/AscensionProtocol.h`, `AscensionMovement.h` | 원본의 **복사본**. 직접 고치지 않는다 |
| `CLNetSession.h/.cpp` | 서버 접속 액터. 수신 스레드 + 게임 스레드 패킷 처리, 60Hz 이동 예측·30Hz 입력 전송·재조정, 매치 상태(라운드·자기장·사망/부활) |
| `CLRemoteHero.h/.cpp` | 다른 플레이어의 겉모습. 서버 위치를 0.1초 늦게 보간한다. 이름표 초록 = 아군, 빨강 = 적 |
| `CombatLab.h/.cpp` | `-AscensionServer` 옵션이 있을 때만 온라인 모드. 로컬 몬스터 생성을 끄고 서버 몬스터를 꼭두각시로 보여 준다. HUD에 접속 상태·매치 진행 표시 |
| `Scripts/OpenOnline.ps1` | 온라인 옵션으로 게임 실행 |

옵션 없이 실행하면 1인 오프라인 데모다. 자동 검증 옵션(`-AscensionVerify` 등)과 함께 쓰면 온라인 모드가 켜지지 않는다.

## 실행 순서 (한 PC에서 두 클라이언트)

1. **서버 켜기**: 서버 저장소 폴더에서. 데모는 시간 배율을 줄여 한 판을 짧게 한다(0.1이면 약 3.6분).
   ```powershell
   .\Scripts\RunServer.ps1 -TimeScale 0.1
   ```
2. **클라이언트 빌드**: 이 저장소 폴더에서 영문 경로의 빌드 폴더를 지정한다.
   ```powershell
   .\Scripts\BuildDemo.ps1 -BuildRoot C:\Builds\AscensionPrototype
   ```
3. **클라이언트 두 개 실행**: 팀을 다르게 고르면 2팀이 모여 10초(배율 적용) 카운트다운 뒤 1라운드가 시작된다.
   ```powershell
   .\Scripts\OpenOnline.ps1 -BuildRoot C:\Builds\AscensionPrototype -Name player1 -Team 1
   .\Scripts\OpenOnline.ps1 -BuildRoot C:\Builds\AscensionPrototype -Name player2 -Team 2
   ```
4. **확인**: 체력바 위 하늘색 줄에 `온라인 매치 · 내 팀 N · 판 1 …`, 화면 위쪽에 `매치 · 1라운드 · 남은 시간 …`이 보이고, 바닥에 파란 자기장 원이 그려지면 성공이다.

- 같은 판에 들어가려면 `-Match` 번호가 같아야 한다(기본 1). 팀은 `-Team 1~4`, 팀당 3명까지다. 넘치면 "팀 N이 가득 찼습니다"가 표시된다.
- 혼자 시험하려면 서버를 `-StartTeams 1`로 켠다.
- 다른 PC의 서버에 붙을 때는 `-Server 192.168.0.10:7777`처럼 서버 PC의 IPv4 주소를 넣는다. 서버 PC에서는 Windows 방화벽에 7777 포트를 한 번 열어 둔다(서버 저장소 README).
- 직접 실행할 때의 옵션: `-AscensionServer=IP:포트 -AscensionName=이름 -AscensionMatch=판번호 -AscensionTeam=1~4 -AscensionMode=match|practice`.

## 매치 화면

- **위쪽 가운데 줄**: 단계(대기·카운트다운·N라운드·축소 중·승리), 남은 시간, 지금 자기장 반지름(m), 밖 피해율, 남은 팀 수, 내 팀. 자기장 밖이면 붉은 글씨.
- **가운데 큰 글씨**: 카운트다운 숫자, "자기장 밖! 안으로 들어가세요", "부활까지 N초", "탈락", "승리! 최후의 1팀"/"팀 N 승리"/"무승부".
- **바닥 원**: 파랑 = 지금 자기장, 흰색 = 축소가 끝날 자리.
- 쓰러지면 1~3라운드는 서버가 잠시 뒤(10/20/30초, 배율 적용) 자기장 안 안전한 곳에서 부활시킨다. R은 매치에서 쓰지 않는다. 4라운드에 쓰러지면 탈락이다.
- 판이 끝나면 결과를 15초(배율 적용) 보여 준 뒤 모두 팀 기지에서 살아나 다음 판을 기다린다.

## 규칙

- 프로토콜을 바꿀 때는 서버 저장소의 원본을 고치고 `kVersion`을 올린 뒤, 이 저장소의 복사본도 같은 시점에 갱신한다. 버전이 다르면 서버가 로그인을 거부하고 HUD에 버전 불일치가 표시된다.
- 연습 방(`-Mode practice`)은 개발 시험용이다(팀·라운드 없음, 최대 3명). 회피·몬스터 판정을 확인할 때만 쓴다.

## 서버 판정 (P1 기술 메모)

### 회피 판정

회피 무적과 공격 명중을 서버가 판정한다.

| 방 | 정원 | 회피 무적 | 회피 입력 되감기 상한 |
|---|---|---|---|
| 매치 | 12명(4팀 × 3명) | 0.30초 | 100ms |
| 연습 방 | 3명 | 0.15초 | 200ms |

- 매치에서는 일반·강공격이 서버 근접 공격(`C_Attack`)으로도 나간다. 서버가 0.35초 뒤 명중을 정해 모두에게 알리고 바닥에 빨간 원으로 예고가 보인다. **같은 팀은 맞지 않는다.**
- 회피하면 누른 시각을 서버에 보낸다. 서버는 명중 시각이 그 회피의 무적 구간 안이면 "정확한 회피", 아니면 피격으로 판정한다. 판정은 명중 후 지연만큼(최대 상한) 기다렸다가 확정하므로 피격 표시가 0.1초 안팎 늦을 수 있다.
- 시험 옵션 `-AscensionNetAutoDodge`: 나를 노린 공격을 하나 걸러 하나씩 자동으로 회피한다(화면 없는 검증용). 연습 방 내려찍기 시험 패턴은 서버를 `-PracticeSlamMs 1500`으로 켠다.

### 충돌 지형

서버가 맵의 기둥·벽·바위를 알고 이동과 공격을 지형으로도 검사한다. 클라이언트 이동 예측도 같은 파일(`Data/ServerCollision/CombatLab.txt`)을 읽는다. `BuildDemo.ps1`이 이 폴더도 빌드 사본에 복사한다.

- **맵(CreateMap.py)을 바꾸면 다시 내보내고 서버 저장소 `data/`에 복사한다.**
  ```powershell
  & "C:\Program Files\Epic Games\UE_5.8\Engine\Binaries\Win64\UnrealEditor-Cmd.exe" "$PWD\AscensionPrototype.uproject" -run=pythonscript "-script=$PWD\Scripts\ExportServerCollision.py" -unattended -nullrhi -nosplash
  # 결과: Data\ServerCollision\CombatLab.txt → 서버 저장소 data\CombatLab.txt
  ```
- 내보낸 파일이 실제 충돌과 같은지 확인한다(로그에 `ASCENSION_COLLISION_VERIFY PASS`).
  ```powershell
  & "C:\Program Files\Epic Games\UE_5.8\Engine\Binaries\Win64\UnrealEditor-Cmd.exe" "$PWD\AscensionPrototype.uproject" -game -nullrhi -unattended -nosplash -AscensionCollisionVerify -abslog="$PWD\Saved\Logs\CollisionVerify.log"
  ```
- 에디터 커맨드렛 실행 뒤 `Config/DefaultEngine.ini`에 Android 파일 서버 설정이 자동으로 붙을 수 있다. 커밋하지 않는다.

### 서버 권한 이동

- 60Hz 고정 틱마다 이동 방향·회피 입력을 만들어 바로 움직이고(예측), 30Hz로 묶어 서버에 보낸다. 서버 결과(`S_MoveAck`)가 오면 그 상태에서 남은 입력을 다시 돌린다(재조정). 차이는 약 0.1초 동안 녹인다.
- HUD 하늘색 줄에 "예측 보정 N회(최대 Xcm)"가 보이면 서버와 클라이언트 계산이 어긋난 것이다. 정상이면 나오지 않는다.
- 온라인 이동은 2D라 기둥 받침(40cm)에 올라서지 않고 둘레로 돈다.
- 시험 옵션 `-AscensionNetAutoMove`: 원을 그리며 달리고 2.5초마다 회피한다.

### 몬스터와 검기

- 매치와 연습 방의 몬스터는 서버가 움직이고, 검기 명중·몬스터의 공격·사망도 서버가 판정한다. 빈 방이 필요하면 서버를 `-NoMonsters`로 켠다.
- 화면의 몬스터는 `ACLEnemy`를 꼭두각시로 쓴 것이다. 위치·상태는 0.1초 늦게 보간하고, **공격 예고는 서버가 알린 명중 시각까지 지연 없이** 보여 준다.
- 검기를 쏘면 그 순간 서버에 알린다. 로컬 검기는 날아가는 모습과 즉시 타격감만 맡고, 피해 숫자·넉백·사망은 서버 결과로 나온다.
- 시험 옵션 `-AscensionNetAutoHunt`: 가장 가까운 몬스터를 자동 공격한다.

## 아직 온라인에 없는 것

- 경험치·레벨업·스킬 포인트·스탯, 검/활 스킬의 서버 판정(스킬은 지금 1인 플레이 몬스터에만 맞는다), 특성, 균열, 황금 고블린.
- 플레이어 사이 공격은 시험용 근접 공격(20 피해)뿐이고 검기는 플레이어를 맞히지 않는다.
- 이전 기획 기능(수문장·각성·장비 드롭·자동 번개/칼날)은 온라인에서 꺼져 있다.
- 서버 주소는 IPv4만 지원한다(`localhost`는 127.0.0.1로 바꿔 처리). 이름은 UTF-8 31바이트(한글 약 10자)까지 전송된다.
