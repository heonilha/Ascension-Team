# Meshy 모델 제작과 적용

사용자 승인: 데모에 필요한 모델을 Meshy로 제작하되 추가 비용을 발생시키지 않는다. 기존 크레딧만 사용하며 결제·크레딧 구매·유료 에셋 구매는 금지한다. 크레딧 부족 시 임시 모델로 개발을 계속한다.

후속 사용자 제한: 연결 시 1,700 크레딧. **데모용 누적 사용 최대 700, 계정 잔액 최소 1,000 유지.** 700은 목표 사용량이 아니라 상한이다. 생성마다 최신 잔액과 예상 비용을 확인하고, 예산이 부족한 요청은 차단한다. 값싼 공통 모델 하나를 먼저 검증하고 재사용한다. 반복 생성·고해상도 옵션·새 장식 모델은 필요성이 확인될 때만 진행한다.

키는 사용자 PC의 LocalAppData/AscensionPrototype/Secrets에 Windows DPAPI로 암호화해 저장한다. 프로젝트·채팅·로그·배포물에 키를 넣지 않는다. 첫 연결은 잔액 조회만 수행한다. 이는 직접 REST API 연결이며 MCP 설치 완료를 뜻하지 않는다.

우선순위:

1. 리깅 가능한 공통 인간형 캐릭터 하나. 플레이어와 적의 변형/색을 재사용해 크레딧 소모를 줄인다.
2. 검 하나. 캐릭터 손에 합쳐 생성하지 않고 별도 장착한다.
3. 모델이 부족하면 검병/돌진병/엘리트는 공통 모델의 크기·색·표식으로 구분한다.
4. 초기 이동·공격·회피 애니메이션은 실제 생성/다운로드 가능 범위를 확인해 연결한다. 모델 생성 성공을 애니메이션 완성으로 보고하지 않는다.

스타일 제안: 가독성 좋은 스타일화된 어두운 판타지. 인간형, 단순한 갑옷, 망토·긴 옷·복잡한 장식 제외, 손과 다리 분리, 정면 A/T 포즈, 무기와 방패 없이 생성. 모델은 바닥 기준 약 180cm로 맞추고 캡슐 충돌을 유지한다.

생성 전 잔액·모델 지원·예상 크레딧을 공식 문서로 확인한다. 우선 한 개로 임포트·재질·스케일·리깅 가능성을 검증한다. 반복 생성 대신 기존 모델의 재사용을 우선한다. 잔액·소모 크레딧·품질·출처를 기록한다.

## 2026-10-11 실제 제작 기록

| 작업 | 사용 크레딧 |
|---|---:|
| 공통 인간형 미리보기(meshy-6-lite) | 5 |
| 텍스처 생성 | 10 |
| 리깅과 기본 달리기 | 5 |
| 대기·검 공격·회피·강공격 4개 동작 | 12 |
| 합계 | 32 |

잔액 API 확인: **1,668**, 최소 유지액보다 668 많음. 추가 결제 없음. 남은 허용량은 사용 목표가 아니며 재생성을 진행하지 않는다. 생성 영수증·상태·원본 FBX/GLB는 Assets/Meshy/SharedKnight에 보존한다. 실행용 에셋은 Content/Models에 있다.

플레이어와 세 종류 적이 공통 모델을 사용하고 기존 색 윤곽·이름으로 구분한다. 스켈레탈 메시의 충돌은 끄고 기존 캡슐과 전투 판정을 유지했다. 모델 높이는 180cm, 루트 이동은 제거했다. 플레이어는 손 뼈에 임시 검을 부착한다. 적의 이동 동작은 적용했지만 공격 전용 동작과 자연스러운 전환은 후속 작업이다.
