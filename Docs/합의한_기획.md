# 새 프로젝트: 각성과 탐욕의 탑

작성일: 2026-10-11. 프로젝트명 AscensionPrototype은 임시 개발명이다.

## 이번 대화의 합의

- 기존 TowerDemo를 사용하거나 변경하지 않고 새 Unreal 프로젝트로 시작한다.
- 캐릭터 뒤에서 높고 멀리 보는 3인칭. 마우스로 카메라와 공격 방향을 조절하고 선택형 락온을 제공한다.
- 검 일반 공격·강공격·회피·스킬 중심의 빠른 액션. 정확한 회피 후 다음 공격을 강화한다. 방패·패링은 보류한다.
- 엘리트 처치 또는 위험한 제단에서 각성 후보 3개 중 하나를 선택한다.
- 각성은 최대 3개. 가득 찼다면 기존 하나를 교체하거나 새 각성을 포기한다.
- 일반 각성에는 대가가 없다. 선택 사항인 탐욕 각성은 강력한 효과와 소리·시각적 노출·긴 빈틈 등 명시적인 대가를 가진다.
- 각성은 해당 생명에 귀속된다. 다른 사람이 약탈할 수 없고 사망하면 초기화한다.
- 장비는 검과 방어구. 공격·생존 성능을 담당하고 사망 시 드롭되어 동료와 다른 파티 모두 약탈할 수 있다.
- 새 합의는 '장비만 약탈'이다. 원안의 소지품·골드 전량 드롭과 다르며, 골드·소모품의 별도 사망 처리는 아직 정하지 않았다.
- 첫 플레이 테스트는 전투층 하나, 검병·돌진병·2연격 엘리트로 구성한다.
- 검병은 회피 후 반격, 돌진병은 측면 회피와 빈틈 공략, 엘리트는 두 번째 공격까지 판단하도록 한다.
- 1인용 전투·각성 검증 → 파티 역할 봇 → 실제 멀티플레이 순서.

## 첫 단계의 목표

작은 공간에서 이동·카메라·검·회피와 공격 전조를 직접 시험할 수 있게 한다. 이후 각성 선택을 연결해 각성 전후 행동 차이를 확인한다.
첫 단계만으로 전체 탑·약탈·D1/D2가 완성되었다고 표시하지 않는다.

## 아직 논의할 항목

- 일반 연속 공격의 횟수와 입력 버퍼, 정확한 회피 보상 수치.
- 스킬 종류·재사용시간, 각성 목록·등장 확률·교체 조건.
- 탑 전체 층수·시간·베이스 보호는 최신 지시서를 참고하되 현재 전투층 테스트와 구분한다.
- 골드·소모품의 사망 처리. 새 기획에서는 장비 외 약탈을 자동으로 추가하지 않는다.
- 모델 스타일·애니메이션·사운드·최종 게임명.

## 모델과 에셋

첫 테스트는 엔진 기본 도형으로 진행 가능하다. 최종 3인칭 전투에는 리깅된 캐릭터와 이동·검 공격·강공격·회피·피격·사망 애니메이션이 필요하다.
모델 구매는 현재 필요 없으며 사용자 승인 없이 유료 에셋을 구매하지 않는다.

## 사용량 중단 기준

사용자는 하루 토큰 잔량 30% 이하에서 중단하도록 요청했다. 현재 도구는 일일 토큰 잔량을 제공하지 않고 5시간·주간 사용률만 제공한다.
2026-10-11 사용자 최신 지시: **5시간 한도 잔여율 25% 이하에서 중단한다. 주간 잔여율은 중단 기준이 아니다.** 기존 30% 기준을 대체한다.
리셋 크레딧을 사용하거나 자동으로 재개하지 않는다.


## 2026-10-11 생존 전투 방향 선택

사용자가 1번인 수동 검 공격 + 자동 보조 능력 + 경험치 강화를 선택했다. 5분 생존 → 보스 처치 → 탈출 흐름을 첫 프로토타입에 적용한다. 번개·회전 칼날로 시작하며 적 처치 경험치로 세 가지 강화 중 하나를 선택한다. 성장과 각성은 해당 생명에만 유지하고 장비만 약탈 가능하다. 다층 탑·실제 PvP는 별도 후속 범위다.

## 2026-10-11 개방형 전투 구역 방향
사용자가 개방형 구역을 층마다 연결하는 방향을 선택했다. 먼저 현재 전투장을 폐허 정원으로 바꾸고, 중앙 광장·기둥/바위 우회로·각성 제단을 배치한다. 현재 단계는 한 구역의 이동/전투 시험이며 기존 5분 생존·보스·탈출 규칙을 유지한다. 다음 단계는 전투층 연결과 층 체류시간/출구 선택이며 이번 맵 변경만으로 등반이나 PvPvE를 구현했다고 간주하지 않는다. 장비 드롭은 사용자의 요청에 따라 임시 숨김을 유지한다.

## 2026-10-11 중앙 수문장과 층별 고정 난이도
사용자가 사냥/강화 후 중앙 수문장 소환·처치를 통과 조건으로 하는 방향에 동의했다. 현재 데모는 전투1층→전투2층→마지막 휴식 구역으로 연결하며 동일 폐허 지형을 재사용한다. 중앙300cm 안에서 E로 소환하고 처치 후 E로 이동한다. 5분 자동보스/강제이동 규칙은 이번 합의로 대체한다. 수문장 소환 이후 추가증원은 멈추며 기존 적은 남는다. 성장·각성·장비는 층 이동으로 초기화되지 않고 사망/새 도전에서 초기화한다.

사용자가 기존 유저의 장기 사냥과 신규 유저의 진입 난이도, 몹 몰이를 지적했다. 몬스터의 체력은 층 기준으로 고정하고 체류시간은 증원 압박만 높인다. 몹 몰이 방지를 위한 추적 범위 제한·베이스 배치·진입 보호 중 어그로 제외·보스 영역 복귀는 향후 멀티 단계의 제안이며 아직 구현/검증되지 않았다. 현재 진행 상태는 1인용 전역 모드다. 다른 유저가 있는 공유 층에 그대로 적용하거나 한 사람의 처치/이동으로 모두를 이동시키는 멀티 규칙으로 간주하지 않는다.
